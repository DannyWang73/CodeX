# NGINX Cookbook 

A comprehensive collection of production-ready NGINX configuration examples, recipes, and best practices for common web server scenarios.

## 📖 Overview

This repository contains curated NGINX configurations extracted from official documentation and real-world deployments. Each recipe is tested, documented, and ready to adapt to your infrastructure.

## 📚 What's Inside

- **Reverse Proxy Configurations** - Load balancing, upstream servers, health checks
- **SSL/TLS Setup** - Modern security configurations, Let's Encrypt integration
- **Performance Tuning** - Caching, compression, connection optimization
- **Security Hardening** - Rate limiting, access controls, DDoS protection
- **Common Use Cases**:
  - Static file serving
  - WebSocket proxying
  - API gateway patterns
  - Microservices routing
  - WordPress/PHP-FPM
  - Node.js/Python app hosting
